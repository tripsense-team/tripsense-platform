# Feature Templates

TripSense uses a **Single-File Feature Plan** format to minimize token waste and provide a unified, easy-to-review document for human approval.

## Standard Template (Recommended)

- [feature-plan-template.md](feature-plan-template.md): The unified single-file specification covering Goals, Architecture, API, Data Model, Security, Trade-offs, and Tasks. Copy this file to `docs/features/<feature-name>.md`.

## Legacy Multi-File Structure (Deprecated)
For backwards compatibility with existing multi-file features:
- `requirements.md`, `architecture.md`, `api.md`, `data-model.md`, `security.md`, `decisions.md`, `implementation-plan.md`, `test-plan.md`.
