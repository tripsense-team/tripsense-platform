# Domains

Domain documents capture business concepts, ownership, invariants, and state transitions. Create a focused domain document when a feature introduces durable domain knowledge.

## Known Domain Areas

- Trip planning and lifecycle
- Places and location context
- Itineraries and schedules
- Reviews and ratings
- Identity and user profile concepts
- Notifications
- AI-assisted recommendations
